## Як перебудувати ноутбук

```bash
python tools/build_nb03.py experiments/03_struktura_i_haby.ipynb          # згенерувати код і текст
jupyter nbconvert --to notebook --execute --inplace \
        --ExecutePreprocessor.timeout=7200 experiments/03_struktura_i_haby.ipynb   # виконати
```

- **Робоча папка.** Ноутбук виконується в `experiments/`: `nbconvert` бере папку ноутбука як робочу, тому шляхи `../data`, `../results` і `../figures` у ноутбуках правильні.
- **Що перезаписується.** Виконання перезаписує відповідні рисунки `figures/0N_*.png` і таблиці `results/0N_*.csv`.
- **Висновок не перераховується.** Його текст береться з `tools/conclusions/concl0N.md` таким, як є. Якщо після зміни коду чи даних числа зміняться, висновок треба оновити вручну за новими результатами.
- **Ноутбук 07** залежить від таблиць п. 5 і п. 6 у `results/`: підсумкова таблиця стійкості читає `05_metaqa_pary.csv`, `06_metaqa_byudzhet_khop.csv` і `06_metaqa_obranyi_vs_bazovi.csv`. Тому `05` і `06` треба виконати раніше за `07`.
- **Ноутбук 07** при першому запуску сам готує підграф MetaQA з seed = 1 (`data/metaqa/processed/movies500_seed1/`), якщо його ще немає.

## Швидка перевірка ноутбука 07 (зменшені розміри)

```bash
SMALL=1 python tools/build_nb07.py experiments/_smoke07.ipynb
jupyter nbconvert --to notebook --execute --inplace experiments/_smoke07.ipynb
rm experiments/_smoke07.ipynb
```

У режимі `SMALL=1` рисунки й таблиці пишуться в `/tmp/reldiff_smoke/smoke07`, а `results/` і `figures/` не змінюються. Підсумкова таблиця стійкості все одно читає результати п. 5 і п. 6 з `results/`. Цей режим лише перевіряє, що код працює. Його числа не використовувати.

## Як перебудувати матеріали для звіту

```bash
python tools/build_dlya_zvitu.py
```

Скрипт:
- бере висновки дослівно з останніх комірок ноутбуків `experiments/00–07`, тому спершу треба оновити ноутбуки;
- перевіряє, що перелік рисунків і таблиць у ньому збігається з фактичним вмістом `figures/` і `results/`, і не збирає документ, якщо щось пропущено або зайве. Після додавання рисунка чи таблиці допишіть підпис у списки `FIGS` або `TABS` у скрипті;
- запускає `pytest`, щоб вписати поточну кількість тестів.

## Окремо виконані комірки

Три комірки в наявних ноутбуках виконано окремо в тому самому середовищі, а їхній вивід вставлено в ноутбук без повного перерахунку:
- `06`: розбір нормування за типом відповіді;
- `07`: якість при заміні вузла запиту на SBM;
- `07`: перерахунок п. 7.2 з детермінованим порядком.

Усі три є в генераторах і при повному перебудуванні ноутбука виконуються разом з рештою.
