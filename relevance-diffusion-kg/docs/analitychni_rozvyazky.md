# Аналітичні розв'язки на простих графах

Позначення з CLAUDE.md: розподіли — вектори-рядки; P = D⁻¹W; вузол запиту q, s = e_q.

- PPR: π* = α·s·(I − (1 − α)P)⁻¹, тобто π* = α·s + (1 − α)·π*·P.  (1)
- Теплове ядро: u(t) = s·e^(−tL), L = I − P.  (2)
- Блукання без перезапуску: π_k = s·P^k; ліниве блукання: π_k = s·((I + P)/2)^k.  (3)

Загальний прийом для (2) і (3): якщо s = Σ_m c_m·φ_m, де φ_m — ліві власні вектори P (φ_m·P = λ_m·φ_m), то

- s·P^k = Σ_m c_m·λ_m^k·φ_m;
- u(t) = Σ_m c_m·e^(−t(1 − λ_m))·φ_m;
- для PPR π* = Σ_m c_m·α/(1 − (1 − α)λ_m)·φ_m.  (4)

Коли використовуємо (1) напряму, корисно пам'ятати: сума рівнянь системи (1) дає Σπ = α + (1 − α)Σπ, тобто Σπ = 1. Тому одне з рівнянь можна замінити умовою нормування.

---

## 1. Повний граф K_n

P = (J − I)/(n − 1), де J — матриця з одиниць. Власні значення P: λ = 1 (вектор 1, кратність 1) і λ = −1/(n − 1) (кратність n − 1, вектори з нульовою сумою).

Розклад: e_q = (1/n)·**1** + (e_q − (1/n)·**1**).

**Блукання без перезапуску:**

(s·P^k)_q = 1/n + (1 − 1/n)·(−1/(n − 1))^k, (s·P^k)_j = 1/n − (1/n)·(−1/(n − 1))^k, j ≠ q.  (5)

Для n ≥ 3 маємо |λ₂| = 1/(n − 1) < 1, тому розподіл збігається до рівномірного = d/Σd (усі степені однакові).

**PPR.** За симетрією π_q = a, π_j = b (j ≠ q). Оскільки (πP)_j = (1 − π_j)/(n − 1), з (1):
a = α + (1 − α)(1 − a)/(n − 1), звідки

π_q = (α(n − 2) + 1)/(n − α), π_j = (1 − α)/(n − α), j ≠ q.  (6)

Перевірка: (α(n − 2) + 1) + (n − 1)(1 − α) = n − α ✓.

**Теплове ядро.** 1 − λ₂ = n/(n − 1), тому

u_q(t) = 1/n + (1 − 1/n)·e^(−tn/(n − 1)), u_j(t) = (1/n)·(1 − e^(−tn/(n − 1))), j ≠ q.  (7)

---

## 2. Цикл C_n (вузли 0, …, n − 1, q = 0)

P = (S + S⁻¹)/2, де S — циклічний зсув. Власні вектори — гармоніки, λ_m = cos θ_m, θ_m = 2πm/n, m = 0, …, n − 1.

**Теплове ядро** (дискретне перетворення Фур'є):

u_j(t) = (1/n)·Σ_{m=0}^{n−1} e^(−t(1 − cos θ_m))·cos(θ_m·j).  (8)

**Блукання:** (s·P^k)_j = (1/n)·Σ_m cos^k θ_m·cos(θ_m·j).  (9)

- Непарне n: усі |cos θ_m| < 1 при m ≠ 0, тому розподіл збігається до 1/n.
- Парне n: є λ = cos π = −1, тому розподіл коливається з періодом 2 (граф дводольний).
- Ліниве блукання: λ' = (1 + cos θ_m)/2 ∈ [0, 1], тому воно збігається завжди.

**PPR у замкненому вигляді.** Для j ≠ 0 рівняння (1) мають вигляд π_j = (1 − α)(π_{j−1} + π_{j+1})/2. Це лінійна рекурентність з характеристичним рівнянням

(1 − α)r² − 2r + (1 − α) = 0, r = (1 − √(α(2 − α)))/(1 − α) ∈ (0, 1).

Корені — r і 1/r. Розв'язок, симетричний відносно q (j ↔ n − j), має вигляд π_j = C·(r^j + r^(n−j)). Він задовольняє всі рівняння при j = 1, …, n − 1. Рівняння при j = 0 замінюємо нормуванням:

Σ_{j=0}^{n−1}(r^j + r^(n−j)) = (1 + r)(1 − r^n)/(1 − r), тому

π_j = (1 − r)/((1 + r)(1 − r^n))·(r^j + r^(n−j)), j = 0, …, n − 1.  (10)

**Висновок:** на циклі PPR спадає з відстанню від вузла запиту **геометрично** зі знаменником r(α). Наприклад, r ≈ 0.557 при α = 0.15 і r ≈ 0.724 при α = 0.05. Чим менше α, тим повільніше спадання, тобто тим менш локальний розподіл.

## 3. Ланцюжок P_n (вузли 0, …, n − 1)

**Прийом «складання» циклу.** Розглянемо цикл C_N з N = 2(n − 1) вузлами і відображення
f(j) = min(j, N − j): вузли j і N − j циклу «склеюються» у вузол f(j) ланцюжка.

- Вузол 0 циклу має двох сусідів (1 і N − 1), і обидва переходять у вузол 1 ланцюжка. Отже, з кінця ланцюжка блукання переходить у вузол 1 з ймовірністю 1 ✓.
- Те саме для кінця n − 1: сусіди n − 2 і n циклу обидва переходять у n − 2 ✓.
- Для внутрішніх вузлів ймовірність переходу до кожного сусіда дорівнює 1/2 ✓.

Отже, розбиття вузлів циклу {j, N − j} є **агрегованим** (lumpable) для ланцюга Маркова: образ блукання на C_N — це блукання на P_n. Оскільки PPR, теплове ядро і блукання є функціями від розподілу блукання, для вузла запиту q (0 ≤ q ≤ n − 1) маємо

x^(P_n)_j = x^(C_N, q)_j + x^(C_N, q)_{N−j} для 0 < j < n − 1; x^(P_n)_0 = x^(C_N, q)_0; x^(P_n)_{n−1} = x^(C_N, q)_{n−1}.  (11)

Тут x — будь-який із розподілів (1)–(3), а x^(C_N, q) — розв'язок на циклі з вузлом запиту q. Розв'язок на циклі з вузлом запиту q — це розв'язок (8)–(10), зсунутий на q.

Зокрема, для q = 0 (кінець ланцюжка) з (10):
π_j = 2C·(r^j + r^(N−j)) для 0 < j < n − 1, π_0 = C·(1 + r^N), π_{n−1} = 2C·r^(n−1), де C = (1 − r)/((1 + r)(1 − r^N)).  (12)

Ланцюжок дводольний (λ = −1 є серед власних значень складеного циклу C_N, бо N парне). Тому блукання без перезапуску коливається, а ліниве блукання і теплове ядро збігаються до d/Σd, де d = (1, 2, …, 2, 1).

## 4. Зірка S_m (центр c, m листків)

Степені: d_c = m, d_ℓ = 1. Стаціонарний розподіл: d/Σd = (1/2 у центрі, 1/(2m) у кожному листку).

Власні значення P: 1, −1 і 0 (кратність m − 1). Ліві власні вектори:

- φ₊ = (1; 1/m, …, 1/m) — для λ = 1, з точністю до нормування це d/Σd;
- φ₋ = (1; −1/m, …, −1/m) — для λ = −1;
- w = (0; w_ℓ) з Σw_ℓ = 0 — для λ = 0.

**Вузол запиту — центр.** e_c = ½φ₊ + ½φ₋. Звідси:

- блукання: π_k = ½φ₊ + ½(−1)^k·φ₋ — коливається між «уся маса в центрі» та «уся маса рівномірно на листках»;
- ліниве блукання (λ' = (1 + λ)/2: 1, 0, ½): π_k = ½φ₊ при k ≥ 1, тобто **точно** стаціонарний розподіл уже після першого кроку;
- теплове ядро: u_c(t) = (1 + e^(−2t))/2, u_ℓ(t) = (1 − e^(−2t))/(2m);  (13)
- PPR: π_c = 1/(2 − α), π_ℓ = (1 − α)/((2 − α)m).  (14)

**Вузол запиту — листок ℓ.** e_ℓ = ½φ₊ − ½φ₋ + w, де w = (0; δ_{ℓj} − 1/m). Звідси:

- теплове ядро (1 − λ = 0, 2, 1 відповідно):
  u_c(t) = (1 − e^(−2t))/2,
  u_ℓ(t) = (1 + e^(−2t))/(2m) + (1 − 1/m)·e^(−t),
  u_j(t) = (1 + e^(−2t))/(2m) − e^(−t)/m для j ≠ ℓ;  (15)
- PPR (з (1) напряму: a = π_c = (1 − α)(1 − a)):
  π_c = (1 − α)/(2 − α), π_ℓ = α + (1 − α)π_c/m, π_j = (1 − α)π_c/m для j ≠ ℓ.  (16)
- ліниве блукання: π_k = ½φ₊ − ½·0^k·φ₋ + 2^(−k)·w, тобто при k ≥ 1 відхилення від стаціонарного розподілу дорівнює 2^(−k)·w.  (17)

Перевірка (16): π_c + π_ℓ + (m − 1)π_j = π_c + α + (1 − α)π_c = (1 − α)/(2 − α)·(2 − α) + α = 1 ✓.

---

## 5. Загальні оцінки, які теж перевіряємо

- **Збіжність ітерацій PPR.** π_k − π* = (1 − α)^k·(s − π*)·P^k, а ‖x·P‖₁ ≤ ‖x‖₁ для стохастичної P. Тому
  ‖π_k − π*‖₁ ≤ (1 − α)^k·‖s − π*‖₁ ≤ 2(1 − α)^k.  (18)
- **Критерій зупинки.** З (18) випливає ‖π* − π_{k+1}‖₁ ≤ ‖π_{k+1} − π_k‖₁·(1 − α)/α. Це гарантована апостеріорна оцінка, і за нею зупиняємо ітерації.  (19)
- **Граничні випадки:** α = 1 ⇒ π* = s; t = 0 ⇒ u = s; t → ∞ ⇒ u → d/Σd (неорієнтований зв'язний граф, зокрема дводольний); α → 0 ⇒ π* → d/Σd (середнє за Чезаро, теж і для дводольного графа).
